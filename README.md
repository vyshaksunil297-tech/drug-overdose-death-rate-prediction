Drug Overdose Death Rate Analysis (EDA)
📌 Overview

This project performs Exploratory Data Analysis (EDA) on drug overdose death rate data to uncover trends, patterns, and insights across different demographic groups and time periods.

The goal is to better understand how overdose death rates vary by age, sex, and year using data cleaning and visualization techniques.

📁 Dataset

The dataset contains information such as:

Year

Age group

Sex and demographic categories

Drug overdose death rates (Estimate)

Additional categorical and numerical indicators

🔧 Data Preprocessing

The following steps were performed:

Removed unnecessary columns

Handled missing values

Cleaned and formatted data

Encoded categorical variables where needed

Scaled numerical features (if required)

📊 Exploratory Data Analysis

Key analysis includes:

Trend of overdose death rates over time

Comparison across age groups

Gender-based analysis

Distribution of death rates

Identifying patterns and anomalies

📈 Visualizations

The project uses visualizations such as:

Line plots (time trends)

Bar charts (category comparisons)

Histograms (distribution)

Heatmaps (correlation insights)

🔍 Key Insights

Overdose death rates show noticeable trends over time

Certain age groups are more affected than others

Differences exist across demographic categories

Patterns highlight important public health concerns

🛠️ Technologies Used

Python 🐍

Pandas

NumPy

Matplotlib / Seaborn

Jupyter Notebook

🎯 Objective

To analyze and understand drug overdose death rate patterns using data-driven insights and visualization techniques.
